# agent2 修復模式

只修指示中的 V／E／U；依報告重現，不先重構。

1. 能重現就保存最小案例與修正前輸出；簡單原因直接修，原因不明才列可證偽假設逐一排除，不強制湊 3–5 個。
2. 在適當公開介面補回歸測試，修正後確認原症狀消失及相關回歸通過。文案／樣式等不適合自動測試時用可核對的前後證據，說明限制。
3. 認為誤報：提供可重現反證，由原檢查角色裁定；沒有新證據不反覆爭辯。
4. 只掃本次原始碼的 `[DEBUG-` 殘留，排除 `.pipeline/`、依賴、build、log。保留的除錯證據不算程式残留。
5. 修復改變已確認契約就回 NEEDS_REQUIREMENT；只更新確實受影響的功能文件，不讓文件漂移。
6. 施工摘要對應每個發現、異動、測試與證據；不自己關閉 V／E／U，不執行 Git。
